# Pizza Restaurant Landing Page

A modern, highly responsive landing page concept designed for a pizza restaurant. It showcases an interactive food and beverage menu, custom image hover dynamics, and a multi-branch location section. Built with **HTML5**, **Tailwind CSS**, **Vanilla JavaScript**, and bundled using **Vite**.

## 🚀 Live Demo

Explore the live project here: [https://jesusmoreno71.github.io/pizza-restaurant-landing/](https://jesusmoreno71.github.io/pizza-restaurant-landing/)

## ✨ Key Features

- **Interactive Menu Showcase:** Structured section categorizing specialty pizzas, beverages, and side dishes.
- **Dynamic Hover Effects:** Custom image transitions and visual feedback on interactive menu cards.
- **Branch Locations & Contact:** Dedicated section displaying physical restaurant locations and operating hours.
- **Utility-First Styling:** Clean, scalable layout built with Tailwind CSS for seamless multi-device responsiveness.
- **Fast Build Pipeline:** Asset bundling and instant HMR powered by Vite.

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** Tailwind CSS (via `@tailwindcss/vite` plugin)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Build Tool / Bundler:** Vite
- **Deployment:** GitHub Pages (via GitHub Actions)

## ⚙️ Development & Local Setup

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/jesusmoreno71/pizza-restaurant-landing.git](https://github.com/jesusmoreno71/pizza-restaurant-landing.git)
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📌 Project Purpose
Created to practice Tailwind CSS integration within a Vite environment, building commercial UI components for food services, and automating modern deployment workflows using GitHub Actions.
